# 검증 기록 — 2026-11-08

## 범위와 절차

스킬 없는 합성 과제 A 1회, 최초 스킬로 과제 A·B 각 1회, 코칭 표현 보완 후 새 문맥에서 과제 B 1회를 수행했다. 모두 별도 대화 문맥이며 입력은 합성이다. 작성자와 실행 에이전트는 다르지만 표본이 작고 무작위·맹검 성능 비교가 아니므로 일반 효과를 계산하지 않는다.

초기 통제 응답은 핵심 사실을 이미 보존했다. 없던 실패를 만들어 새 스킬의 효과로 보고하지 않는다. 평가 기준 중 면담→코칭 확대는 최초 B 출력 뒤 추가한 회귀 항목이며, 이를 사전에 정한 지표처럼 보고하지 않는다.

## 계산기

구현 전에 9개 테스트를 실행해 계산기 파일 미구현으로 9개 모두 실패함을 확인했다. 구현 후 동일 테스트 전부 통과했다. 포함·제외, 중복·동일·분리 기간, 현재 재직, 잘못된 월·역전·미래 날짜, 명시적 포함 여부, 제외 사유, 종료일 누락을 검사한다. 최초 실패는 기능 부재를 확인하는 검사이며 잘못된 기존 계산 구현과의 비교는 아니다.

```bash
python3 -m unittest discover -s tests -v
```

최종 계산 테스트: **9/9 통과**. 스킬 형식 검사도 통과했으며, 설치 단위의 로컬 Markdown 링크는 모두 존재한다.

개인 스킬 저장 후 조정된 설치 경로에서도 형식 검사와 동일한 9개 테스트를 통과했다. 설치본의 본문·참조 자료·계산기는 배포 원고와 바이트 단위로 일치한다. 플랫폼이 `agents/openai.yaml`에 아이콘·제품 메타데이터를 추가했으며, 작성한 표시 이름·설명·기본 프롬프트는 그대로 유지된다. `manifest.json`은 저장소 배포 원고의 해시를 기록한다.

응답 원문 두 파일의 Markdown 줄 끝 두 공백은 줄바꿈 표기다. 원문 보존을 위해 유지했으며, Git 공백 검사의 해당 경고를 코드 오류로 세지 않는다.

## 판본과 한계

공개 저장소의 최초 배포 커밋은 `94088b382bba044b0081da56649f0f53573128e8`이다. 원격 `main`이 해당 커밋을 가리키는지 다시 읽었고, 24개 파일의 전체 Git 트리 `9fd6691899853795c3fa7986cf95a210bec27d03`이 검증한 로컬 판본과 일치함을 확인했다. 이후 완료 상태를 기록한 문서 수정과 구별한다.

별도 검토자는 스킬 본문·참고 문서·계산기·README·명세·평가 기준·합성 입력을 읽고 커밋을 막을 실질적 결함을 발견하지 못했다. 검토 시점의 계산 테스트 9개도 통과했다. 다만 마지막에 추가된 이 검증 기록과 B 재실행 원문, 링크 전수 검사는 그 검토자가 완료하지 않았다. 해당 B 출력 대조와 설치 단위 링크·파일 대조는 작성자가 수행한 확인으로 구분한다.

최초 스킬 파일 SHA-256은 후속 보완 전 파일을 재구성해 기록하지 않는다. 실행 중 사용 경로의 판본을 처음부터 모두 동결하지 않았으므로, 출력 비교를 완전한 불변 판본 실험이라고 주장하지 않는다. 최종 배포 파일의 해시는 `manifest.json`으로 별도 기록한다. 이는 최종 배포 확인용이며 과거 실행의 해시로 소급하지 않는다.
