# 합성 과제 E — 직무 기능분류

아래 사례를 스킬의 기능분류로 정리한다. 각 독립 책임에 기능 하나와 짧은 이유를 적고, 정보가 부족하면 필요한 사실을 밝힌다. 복합 사례는 책임을 나누고 대표 기능을 정할 수 있는지도 구분한다. 산업·기술·관리 태그와 기능 코드를 혼동하지 않는다. 채용 자격이나 인사권을 추가하지 않는다.

| ID | 사실 |
| --- | --- |
| E01 | 지주사에서 세 사업의 유지·매각·신규 진입 대안을 비교해 이사회에 사업 포트폴리오를 권고한다. 재무모델의 작성 책임은 재무팀에 있다. |
| E02 | 구독형 서비스의 대상 고객, 요금제별 기능, 제품 우선순위와 출시·종료를 결정한다. 설계·코드 구현은 별도 조직이 맡는다. |
| E03 | 고객사의 ERP와 주문 시스템을 연결하는 소프트웨어를 설계·구현해 인도한다. |
| E04 | 산업용 부품 브랜드의 인지도와 잠재고객 유입 캠페인을 책임진다. 개별 견적·계약은 영업팀이 담당한다. |
| E05 | 기존 고객의 계약 갱신 가격을 협상하고 갱신·확장 계약 실적을 책임진다. |
| E06 | 외주 전문용역의 공급자를 비교·선정하고 구매조건·계약 및 공급자 성과를 관리한다. |
| E07 | 병원의 의약품 수요, 유효기간별 재고, 병동 공급과 운송 계획을 책임진다. 구매계약과 환자 진료는 맡지 않는다. |
| E08 | 병동 간호팀에서 정해진 진료계획에 따른 환자 간호와 일별 직접 돌봄 제공을 책임진다. |
| E09 | 기업 고객의 CRM 도입 교육과 이용 문제를 해결하고 실제 사용 정착을 책임진다. 계약 갱신·매출 권한은 없다. |
| E10 | 회계 전문회사에서 고객사의 결산 수치·세무 신고 자료를 작성한다. 고객에게 유료로 인도하는 업무다. |
| E11 | 회사 내부의 직무·평가·보상 제도와 인재 확보·육성 프로그램을 설계하고 운영한다. |
| E12 | 은행 데이터베이스의 접근 권한, 장애 복구, 가용성과 상시 운영을 책임진다. 새 애플리케이션 개발은 맡지 않는다. |
| E13 | 생산 조직과 별도로 의약품 배치의 규격 적합성을 검증하고 품질 출하 승인을 책임진다. |
| E14 | 법률사무소에서 고객의 계약상 권리·의무를 검토하고 법률 의견을 제공한다. 구매조건 협상이나 계약 성사 책임은 없다. |
| E15 | 전력회사의 비거래 정책 이해관계자·언론과 소통하고 기업 평판과 공공 관계를 관리한다. 판매 캠페인은 맡지 않는다. |
| E16 | 직함은 AX혁신팀장이고 이력서에 AI·데이터 활용만 적혀 있다. 최종 책임 산출물과 수행 업무는 없다. |
| E17 | 고객성공팀장이 고객 이용 정착과 갱신 계약을 각각 책임진다. 공고에서 대표 성과 기준은 갱신 계약금액이라고 명시한다. |
| E18 | PMO라는 이름과 주간 회의·일정 조율만 확인된다. 프로젝트가 인도하는 결과물과 전사 포트폴리오 권한은 확인되지 않는다. |
| E19 | 광고 제작 스튜디오에서 고객이 승인한 캠페인 기획에 따라 영상·디자인 제작물을 인도한다. 캠페인 타깃·예산·유입 성과는 고객사가 결정·책임진다. |
| E20 | 경영지원 담당자가 사업 철수 대안 권고와 다음 해 재무예측 산출을 각각 책임진다. 두 업무의 우선순위·평가 비중·시간 비중은 없다. |
| E21 | 교육기관에서 외부 수강생에게 이미 정해진 교육과정을 수업으로 제공한다. 회사 직원의 육성제도 업무는 아니다. |
| E22 | 개인정보 관련 법률 해석과 전사 준법·통제체계를 책임진다. 시스템 구현·접근 운영은 별도 보안팀이 맡는다. |
| E23 | 소프트웨어 개발자가 구현물 인도의 일부로 단위 테스트를 작성한다. 별도 품질 승인권이나 품질 부서의 성과 책임은 없다. |
| E24 | 제조 현장에서 설비 예방정비와 복구·가동 기반 유지를 책임진다. 생산 수량·작업 지시·출하 승인 책임은 없다. |
| E25 | 승인된 작업 방식에 따라 제품을 생산하고 일별 생산량·납기를 책임진다. 신규 제품 설계나 별도 품질 출하 승인은 맡지 않는다. |
