# 직무 확장 검증 기록 — MECE 요구 이전 후보

기준일 2026-11-08. 이 기록의 C/D는 사용자가 MECE를 추가 요구하기 전 **10군 후보**의 적용 결과다. 최종 15기능 분류의 결과로 소급하지 않는다. 후보 파일은 [당시 본문](pre-mece-snapshot/SKILL.md)과 같은 폴더의 참조 파일로 보존했다. 최종 분류 적용은 [별도 MECE 기록](review-mece.md)을 따른다. 모든 지원자·회사 경력 자료는 합성이다. 실제 합격, ATS 처리, 기업 제출 시스템의 동작을 시험한 기록이 아니다.

## 범위와 판본

- 기준 판본은 공개 `2253f3acc2bed730e56a1f14d8fb7c53bf2721e2`의 0.1.0과 당시 설치본이다. 실제 읽은 파일의 해시는 [기준 판본 기록](baseline-version.json)에 있다.
- 과제 C는 같은 [영업·구매 입력](input-commercial.md)을 변경 전·후 각각 새로운 문맥에서 적용한다. 실행자에게 다른 출력이나 평가 기준을 제공하지 않는다.
- 과제 D는 [경영지원 입력](input-corporate.md)의 추가 적용 확인이다. 변경 전 응답과 비교한 실험이 아니다.
- 당시 후보 해시와 입력 해시는 [적용 판본 기록](application-version.json)에 있다. 실제 읽은 4파일의 원문을 보존했다. 읽지 않은 공고 장부는 당시 해시만 보존하고 현재 장부로 연결한다. 실행자가 실제 읽은 파일은 각 출력과 별도로 기록한다. 후보 파일 목록이 전부 읽혔다는 뜻은 아니다.
- 원문 출력과 [수용 기준](criteria.md)을 사람이 읽고 대조한다. 반복 실행의 통계나 자동 채점 점수를 만들지 않는다.

## 변경 전 관찰

[0.1.0의 C 응답](baseline-commercial.md)은 C1–C10을 충족했다. 회사 재직과 팀장 기간, 직속 5명·1차 평가, 대표의 최종 계약 승인을 보존했다. 60억원은 팀 수주, 35억원은 해당 계약의 당해 인식 매출로 썼고 미체결 20억원을 확정 실적으로 쓰지 않았다. 단가 10% 인하와 조건부 예상 절감 1천만원도 구분했다.

따라서 이번 변경은 확인된 실패를 고쳤다는 주장이나 일반 성능 향상 실험이 아니다. 요청받은 직무 범위를 넓히고 직무별 질문·출처를 명시하는 변경이며, 새 지침 적용 중 사실 경계가 유지되는지 확인한다.

C의 수주·매출 수치와 계약 책임 관계 일부는 직무별 참고표의 합성 영업 예문에도 사용된다. 따라서 새 문맥에서 실행했다는 사실과 별개로 C는 독립적인 미공개 입력에 대한 일반화 검증이 아니다. 예문을 포함한 지침의 적용 확인으로만 해석한다.

수용 기준은 C 10개, D 8개 모두 충족했지만 이는 각 한 번의 합성 적용에 대한 관찰이다. 새 참고표의 모든 직무군, 실제 사용자 자료, 재현 빈도, 실제 채용 결과를 검증한 것은 아니다. C/D 출력 관찰로 유발된 추가 변경은 없었다. 이후 사용자의 MECE 요구로 기능분류를 별도 재설계했다.
