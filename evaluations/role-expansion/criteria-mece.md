# MECE 분류 적용 기준

평가자는 입력과 실제 출력을 대조한다. 실행자에게 이 파일이나 기대 코드를 제공하지 않는다. 실제 직업 세계 전체의 완전성 증명이 아니라, 15개 기능과 경계·정보 부족 처리의 합성 적용 확인이다.

모든 독립 책임에는 기능 한 개만 배정한다. 미확정은 입력 부족 상태로 표시하며 새로운 기타 기능으로 세지 않는다. E16·E18의 기능 미확정과 E20의 대표 기능 미확정은 서로 다르다. 이 검증은 실제 채용 공고를 모든 기능에서 확보했다는 증거가 아니다.
