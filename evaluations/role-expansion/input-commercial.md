# 합성 과제 C — 영업·사업운영

아래 사실로 영업·사업운영 팀장 지원용 경력 요약 2문장과 대표 성과 3개를 한국어로 쓰고, 마지막에 중요한 확인 사항만 적는다.

**지원 JD(합성):** B2B 수주·매출·이익 관리, 파이프라인 예측, 공급사 원가 협상, 팀 코칭.

**경력 사실(합성):**

- D회사 2018.01–2026.10, 영업운영 팀장 2024.01–2026.10.
- 직속 5명, 인사평가 1차 평가자.
- 핵심 고객 2곳의 계약 협상 책임자이나 최종 계약 승인은 대표.
- 팀 연간 수주 목표 50억원, 2025년 체결 계약 총액 60억원. 같은 계약 중 2025년에 인식된 매출 35억원. 계약 전체의 이익 수치는 없음.
- 2025년 12월말 미체결 파이프라인 20억원, 확률 가중치는 정의되지 않음.
- A부품의 동일 사양 단가를 1만원에서 9천원으로 협상, 다음해 예상 구매량 1만개. 실제 발주·입고 수량과 적용 시점 미확인.
- 팀원 5명에게 매주 협상 피드백을 주고, 2명의 실제 제안서를 함께 검토해 가격 조건을 수정한 기록이 있음. 피드백 이후의 성과 인과는 확인되지 않음.
- 회사 전체 매출, 팀 순이익, 실제 구매 절감액의 다른 자료는 없음.
