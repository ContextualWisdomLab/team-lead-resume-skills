# 직무별 책임과 경력 근거 선택

실제 공고에서 중심 책임을 찾고 아래에서 필요한 행을 선택한다. 경영지원·사업운영처럼 여러 기능이 섞인 직무는 관련 행을 조합한다. 회사가 쓰는 직무명과 공식 직책을 보존한다.

아래 자료·지표는 **경력을 확인하기 위한 편집 질문**이다. 모든 회사의 필수 요건이나 지원자가 갖춰야 할 성과 목록이 아니다. 공개 채용 요구와 확인 날짜는 [채용 사례 장부](hiring-cases.md)에 따로 기록한다. 공고와 지원자의 자료에 있는 항목부터 선택한다.

## 공식 사례와 참고표의 연결

[채용 사례 장부](hiring-cases.md)의 식별자를 사용한다. 사례의 일부 책임이 해당 직무군과 겹친다는 뜻이며, 한 사례가 직무군 전체를 대표하거나 모두 인사관리 직책이라는 뜻은 아니다.

| 직무군 | 관련 사례 | 해석 범위 |
| --- | --- | --- |
| IT·개발 | H1, H2, H3 | 사람 관리, 기술 리딩, 프로젝트 리딩을 구분 |
| AX·데이터 | H2, H3, H4 | 데이터 플랫폼·AIOps·사내 AX의 서로 다른 책임 |
| 경영기획·전략 | H5, H6 | 사업계획·의사결정 지원·재무 전략, 공식 직함 유지 |
| 재무·회계 | H6, H5 | FP&A·예산·통제 중심이며 회계·감사 전체 요건은 아님 |
| 인사·조직 | H7 | 채용 전략·운영·코칭 중심이며 HR 전체 요건은 아님 |
| 영업·사업개발 | H8 | 직접 딜 실행과 영업팀 운영 |
| 마케팅·브랜드 | H9 | 북미 커머스·인플루언서 마케팅 사례 |
| 구매·소싱 | H11 | 글로벌 소싱·공급사·조직 책임 |

## 지표 이름과 집계 범위를 먼저 고정하기

수치를 쓰는 항목에는 다음을 확인한다: **지표 이름과 정의 → 대상·기간·단위·분모 → 기준값·비교값·목표 → 자료와 산식 → 본인 행동·팀 결과·승인권**. 문서에 이 작업표를 그대로 넣을 필요는 없다. 확인된 조건을 성과 문장에 남긴다.

| 자료의 종류 | 확인하여 유지할 구분 |
| --- | --- |
| 영업 실적 | 체결 계약 총액, 기간 중 인식한 매출, 거래액, 미체결 파이프라인은 각각 이름과 기간을 유지한다. 목표 달성률에는 어떤 목표인지 붙인다. 확률 가중 예측에는 정의된 단계·확률·기준일이 필요하다. |
| 구매·비용 | 협상한 단가와 실제 적용된 단가를 구분한다. 예상 물량을 곱한 금액은 조건부 예상치다. 실현 절감은 실제 적용 시점·수량·비교 조건으로 대조한다. 단가 절감만으로 총비용·이익 개선을 확정하지 않는다. |
| 예산·손익 | 예산안 작성·조정·승인·집행의 주체를 확인한다. 목표나 전망을 실적으로 바꾸지 않는다. 마진율의 차이와 상대 변화, 매출과 이익, 손익과 현금을 각각 구분한다. |
| HR·운영 속도 | 시작·종료 사건, 영업일·달력일, 평균·중앙값, 처리 완료·미완료 집단을 확인한다. 직무·물량·난도 등이 바뀐 전후 비교에는 그 조건을 남긴다. |
| 비율·퍼널 | 모집단·관찰 기간·중복 처리·분모 정의를 확인한다. 연말 인원을 임의로 평균 재직 인원으로 대체하지 않는다. 단계별 전환과 전체 전환, 광고 귀속과 인과 효과를 구별한다. |

숫자가 없으면 확인된 판단, 협상, 설계, 운영 범위와 산출물을 선택한다. 직무별 지표가 참고표에 있다는 이유로 이력서의 빈칸을 예상 수치로 채우지 않는다. 계산과 인과의 공통 기준은 [증거 절차](evidence-workflow.md)를 따른다.

## 직무 전환과 복합 직무

- 목표 직무의 책임에 대응하는 실제 경험을 고른다. 과거의 공식 직함을 지원 직무명으로 바꾸지 않는다.
- 개발 리더가 제품 리드에 지원하면 고객 문제 정의·우선순위·부서 조율 중 맡은 일을 제시한다. 제품 손익·가격·인사권은 별도 사실이 있을 때 쓴다.
- 경영지원 팀장은 재무·인사·기획을 함께 다룰 수 있다. 직접 수행, 외부 전문가 위탁, 검토, 승인 책임을 업무별로 구분한다.
- 해당 산업의 자격·규제·안전·노무·회계 판단이 요구되면 실제 공고와 보유 자격·담당 범위를 확인한다. 유사한 직무명을 자격이나 법적 책임의 근거로 삼지 않는다.

## 합성 예문 — 영업

자료: 팀의 2025년 수주 목표 50억원, 체결 계약 60억원, 같은 계약의 당해 인식 매출 35억원이다. 후보자는 핵심 고객 2곳의 협상을 맡았고 대표가 최종 승인했다.

작성: `2025년 팀 수주 60억원으로 목표 50억원 대비 120%를 달성한 조직에서 핵심 고객 2곳의 계약 협상을 담당했습니다. 최종 계약 승인은 대표가 맡았으며, 팀 수주 계약 전체의 2025년 인식 매출은 35억원입니다.`

팀 실적과 본인의 협상 책임, 최종 승인, 매출 집계 기간을 함께 보존한다. 고객 2곳의 개별 금액이나 후보자의 기여율은 별도 자료가 있을 때 추가한다.
