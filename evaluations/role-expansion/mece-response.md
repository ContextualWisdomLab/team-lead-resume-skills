| E02 | **F02 상품·서비스 기획·관리** | 대상 고객, 기능, 우선순위, 출시·종료에 관한 제품 의사결정을 책임진다. |
| E03 | **F03 연구·설계·개발·창작** | 시스템 연결 소프트웨어의 설계·구현·인도를 책임진다. 고객사에 인도한다는 조건은 기능을 바꾸지 않는다. |
| E04 | **F04 마케팅·수요개발** | 브랜드 인지도와 잠재고객 유입을 책임진다. |

| E06 | **F06 조달·공급자관리** | 외주 공급자 선정, 구매조건·계약, 공급자 성과가 책임 대상이다. |

| E09 | **F09 고객지원·이용성과관리** | CRM 도입 교육과 문제 해결을 통해 고객의 실제 이용 정착을 책임진다. |
| E10 | **F10 재무·회계·자금관리** | 결산 수치와 세무 신고 자료가 책임 산출물이다. 외부 고객에게 유료로 제공해도 회계 기능에 해당한다. |
| E11 | **F11 인사·조직·노무관리** | 직원의 직무·평가·보상·확보·육성 제도를 책임진다. 제도를 설계한다는 이유로 개발 기능으로 바뀌지 않는다. |
| E12 | **F12 운영기반·자산관리** | 데이터베이스 접근 권한·복구·가용성·상시 운영을 책임진다. 세부 영역은 IT 운영이다. |
| E13 | **F13 품질·안전·환경관리** | 생산과 독립된 규격 적합성 검증과 품질 출하 승인을 책임진다. |
| E14 | **F14 법무·준법·내부통제** | 계약상 권리·의무 검토와 법률 의견이 책임 산출물이다. |
