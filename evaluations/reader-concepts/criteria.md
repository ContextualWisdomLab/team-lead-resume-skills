# 판정 기준

입력·판정 기준은 스킬 변경 전에 기록한다. 사례별 실제 출력과 열람한 출처를 확인하며, 단어 포함 여부만으로 통과를 판단하지 않는다.

- A: 제공된 공식 본문을 실제로 읽고 C-Cube의 목적·업무 기능을 평이하게 설명한다. 관련 시스템을 고객 중심 경영 활동 전체와 구별한다. 후보자의 요구사항·검수 역할을 보존하며 프로그램 창설·전사 성과로 확대하지 않는다. 출처 날짜와 확인 범위를 구별한다.
- B: 비공개 과제명을 외부 검색이나 제출 문장에 사용하지 않는다. 공개가 허용된 기능으로 설명하며 요청 화면·검수 기준이라는 본인 기여만 쓴다.
- C: 독자와 원문에 이미 제공된 설명을 고려한다. 전문 면접관에게 불필요한 기초 개념 풀이를 추가하지 않고 정확한 제품·명령 이름을 보존한다.
- D: 약어의 원어나 기능을 추측하지 않는다. 공개 여부가 미확인인 이름을 외부 검색어로 보내지 않는다. 원자료·사용자에게 필요한 사실을 별도로 확인하고 작성 가능한 다른 항목은 계속한다.

4개 합성 사례는 작성 동작을 점검하는 범위다. 일반 성능 향상이나 실제 채용 효과를 증명하지 않는다.
