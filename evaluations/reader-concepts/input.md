# 외부 독자를 위한 개념 설명: 합성 입력

지원자와 비공개 과제의 정보는 모두 합성이다. C-Cube와 PostgreSQL은 공개 개념이며, 실제 지원자의 경력을 뜻하지 않는다.

## A. 공개 프로그램명

합성 지원자가 C-Cube 관련 시스템의 요구사항 정리·검수를 담당했다. 초안은 ‘C-Cube 고도화 PM을 담당했습니다’이다. 외부 채용담당자가 이해할 수 있게 제출 문장과 짧은 출처 메모를 작성한다. 공식 설명은 https://blog.hyosung.com/4960 에 있다. 후보자가 고객 중심 경영 프로그램 자체를 창설하거나 회사 전체 성과를 책임졌다는 근거는 없다.

## B. 공개할 수 없는 과제명

합성 비공개 과제명 ‘별결-29’는 외부 공개가 허용되지 않는다. 승인된 요약은 ‘부서별 장비 요청을 모아 담당자가 처리 상태를 확인하는 사내 도구, 본인은 요청 화면·검수 기준 정의’다. 별도 성과 수치는 없다. 외부 채용담당자를 위한 제출 문장을 작성한다.

## C. 전문가에게 이미 충분한 설명

데이터베이스 전문 면접관에게 쓰는 상세 경력이다. 초안은 ‘PostgreSQL의 EXPLAIN ANALYZE 결과를 비교하며 쿼리의 실제 실행 계획을 점검했습니다’이다. 본인의 수행 사실은 확인되었다. 목적에 맞게 유지 또는 수정하고 이유를 짧게 쓴다.

## D. 뜻과 공개 범위를 모르는 약어

‘RXP를 도입했다’만 주어졌다. RXP의 원어·목적·공개 여부·지원자의 역할은 확인되지 않았다. 제출본을 작성할 때 어떻게 처리할지 답한다.
