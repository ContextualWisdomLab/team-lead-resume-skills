# Team Lead Resume Implementation Plan

> For agentic workers: use `superpowers:executing-plans` for implementation. Research and independent application checks may run in separate contexts.

**Goal:** 출처에 근거한 팀장급 이력서 작성 스킬을 만들고 설치·검증·커밋한다.

**Architecture:** 스킬은 문서를 중심으로 구성하고 경력 기간 계산만 작은 로컬 스크립트로 제공한다. 기존 한국어 스킬과 문서 형식 스킬은 각자의 책임 범위를 유지한다.

**Tech Stack:** Markdown, YAML, Python 3.10+ 표준 라이브러리, Git.

**Spec:** `docs/superpowers/specs/2026-11-08-team-lead-resume.md`

## 제약과 검토 초점

- 공개된 채용 요구사항과 실제 합격 사례를 혼동하지 않는다.
- 합성 평가만 사용하며 개인 자료를 저장하지 않는다.
- 겹친 재직 기간, 경력 인정 여부가 불명확한 경험, 인사권 없는 리딩, 정성적으로 확인된 효과, 타인이 구현한 결과, 지정 양식을 포함한 입력을 점검한다.
- 계산 결과는 시작·종료 월을 포함한 참고값이다. 정확한 재직 일수나 채용사의 경력 인정 결과로 해석하지 않는다.
- 스킬 작성·검증·설치는 개인 스킬 체크아웃에서 수행하고, 완성본만 새 저장소에 옮긴다.

## Task 1: 출처 조사와 스킬 작성

- [x] 기존 한국어 이력서 지침과 사용 범위를 읽는다.
- [x] 스킬 없이 수행한 합성 과제의 응답을 확보한다. 기준을 이미 충족한 행동을 실패로 꾸미지 않는다.
- [x] 공식 채용 공고와 채용 지침을 직접 열어 출처·날짜·상태·적용 한계를 기록한다.
- [x] `SKILL.md`와 3개 근거 파일에 입력→JD 대응→사실 대조→작성→검증 절차를 쓴다.
- [x] 별도 문맥에서 같은 합성 과제와 직무 조건이 다른 과제를 수행하고 응답 원문을 보존한다.

## Task 2: 재직 기간 계산

**Interface:** `python3 scripts/career_months.py INPUT.json --as-of YYYY-MM`는 `start`, `end`(현재는 null), `include`(boolean)로 표시한 기간의 월 단위 합집합을 JSON으로 출력한다. 제외하는 기록에는 `reason`이 필요하다.

- [x] `tests/test_career_months.py`를 먼저 쓴다. 66개월과 62개월에서 겹친 10개월을 빼면 118개월, 즉 9년 10개월이어야 한다.
- [x] 스크립트를 구현하지 않은 상태에서 테스트가 실패함을 확인한다.
- [x] 스킬 경로에 계산기를 작성한다. 포함 여부가 명시되지 않은 기록은 오류로 처리한다. 시작이 종료보다 늦은 기간, 미래 종료일, 잘못된 월도 오류로 처리한다.
- [x] 전체 테스트와 실제 CLI 호출을 실행한다.
