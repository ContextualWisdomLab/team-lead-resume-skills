# 팀장급 이력서 직무 확장

## 목적과 선택

사용자는 기존 스킬의 직무 확장에 이어 “직무가 MECE하게” 분류되도록 요청했다. IT·개발·AX 중심의 0.1.0 이후 작성한 초기 10군 확장 초안은 기술·프로그램과 기능을 섞었으므로, 최종 책임 산출물을 기준으로 한 15개 기능으로 교체한다. 세부 코드와 경계는 이 스킬의 설계 선택이며 공식 직업 분류와의 일대일 대응이나 보편적인 MECE 인증을 주장하지 않는다.

기존 `team-lead-resume` 하나를 유지하고 직무별 참고표를 추가한다. 직무마다 스킬을 복제하면 사실 확인·양식 규칙이 중복되고, 단순 직무명 추가만으로는 필요한 경력 증거가 달라지는 점을 설명할 수 없다. 공통 절차와 직무별 확인 자료를 연결하는 구성을 선택한다.

## 분류 단위와 15개 기능

한 사람이 독립적으로 책임지는 최종 산출물·성과를 분류한다. 복합 직무는 독립 책임으로 나누며 각 책임에 기능 코드 하나만 부여한다. 하나의 성과를 여러 기능의 별도 실적으로 반복 계산하지 않는다. 결과를 만드는 과정의 모든 행동을 별도 직무로 나누지는 않는다.

정확한 포함·제외 경계와 경계 사례는 [직무별 참고표](../../../skills/team-lead-resume/references/role-families.md)를 기준으로 한다. 대표 기능은 핵심 결과 책임, 명시된 평가 우선순위, 확인된 업무 비중 순으로 정한다. 근거가 부족하거나 동률이면 대표 기능을 미확정으로 두고 확인된 책임별 작성은 계속한다.

산업·서비스 분야, 기술·전문 수단, 역할·관리 범위, 운영 대상, 프로그램·업무 방식은 별도 속성으로 기록한다. AI·데이터, AX·DX·SCM·ESG·PMO, 팀장 같은 명칭으로 기능을 확정하지 않는다. 다른 기능 팀장의 일상 코칭은 관리 범위로 두며, 프로젝트 조율 사실을 구현·승인·인사권으로 확대하지 않는다.

## 산출물과 수용 기준

- 공식 공고 12건(H1–H12)과 공식 지침 5건(G1–G5)을 출처 장부에 기록한다. 지침은 역할·문서 관련 3건과 분류 관련 2건(G4 ILO·ISCO, G5 NCS)이다. 직함만으로 직속 인원·인사권을 추정하지 않는다.
- `references/role-families.md`에 15개 기능의 책임·포함·제외 경계, 별도 속성, 확인할 증거, 지표의 정의·단위·집계 범위, 관련 공고와 미확보 영역을 연결한다. 공고의 요구와 편집 판단을 구분한다.
- 실제 공고의 독립 책임을 대조해 미배정·다중배정·성과 중복을 확인한다. 불확실한 책임을 일반 운영·기타로 강제 배정하지 않으며, 정보 부족과 분류 경계의 공백을 구분해 남긴다.
- 수주·인식 매출·미체결 파이프라인, 예상 절감·실현 절감, 지표의 분모·비교 집단, 코칭 행동·성과를 구분한다. 확인된 행동과 결과는 구체적으로 쓴다.
- SKILL의 검색 조건과 자료 선택, 공통 증거표를 확장한다. 이름·기존 경력 계산기·지정 양식 우선 원칙을 유지한다.
- 개인 자료 없이 합성 과제를 적용하고 기존 판본과 새 판본의 원문·해시·관찰 범위를 기록한다. 기존 판본이 맞힌 행동을 실패로 꾸미지 않는다.
- 개인 스킬 경로에서 작성·검증·저장한 뒤 공개 저장소에 반영한다. 기존 커밋과 동시 작업을 보존하며 일반 커밋으로 배포한다.

## 확보 범위와 검증 상태

기능분류의 범위와 공고 확보 범위는 다르다. F08의 생산·시공·의료·교육 등 본원 서비스와 F09의 고객지원·활용 정착 전담 공고는 미확보다. F13·F14·F15는 다른 공고에서 일부 책임을 확인한 수준이며 비IT 연구·창작, 시설·설비·행정 등도 추가 조사가 필요하다. 미확보 분야는 사용자가 제공한 실제 공고와 경력으로 작성할 수 있으나, 조사하지 않은 자격·채용 요건을 만들지 않는다.

C(영업·구매)·D(경영지원) 합성 과제는 MECE 이전 후보를 대상으로 한 관찰 기록이다. 그 결과를 현재 15기능 분류의 검증 결과로 옮기지 않는다. E 분류 검증은 25개 합성 사례의 수용 기준을 충족했다. 실제 출력과 해시는 별도 평가 기록에 보존하며 한 번의 합성 적용으로 모든 직업의 포괄성을 보장하지 않는다. 0.1.0의 테스트·설치·배포·원격 대조 기록은 당시 판본의 이력으로 보존한다. 이 설계 문서가 현재 수정본의 새 테스트 통과나 배포·원격 검증을 입증하지 않는다.

## 범위의 한계

15개 기능은 경력 근거 선택과 책임 구분을 돕는 사용자 정의 분류다. ILO·NCS를 참고해도 모든 업종·직급·자격 요건을 대표하거나 공식 체계와 동일해지는 것은 아니다. 공공·비영리·특수 전문직은 실제 업무·자격을 추가 검토한다. 특정 자격·규제·산업 지식은 실제 공고와 지원자 자료로 확인하며 실제 합격률·ATS 점수·직무 적격성은 예측하지 않는다. 기존 경력 계산기를 유지하고 새 계산기·외부 의존성을 추가하지 않는다.
