# 팀장급 이력서 직무 확장

## 목적과 선택

사용자는 기존 스킬의 직무 확장에 이어 “직무가 MECE하게” 분류되도록 요청했다. IT·개발·AX 중심의 0.1.0 이후 작성한 초기 10군 확장 초안은 기술·프로그램과 기능을 섞었다. 이를 최종적으로 책임지는 산출물을 기준으로 한 15개 기능으로 교체한다. 세부 코드와 경계는 이 스킬에서 정한 설계이며, 공식 직업 분류와 일대일로 대응하거나 보편적인 MECE 인증을 받았다고 주장하지 않는다.

기존 `team-lead-resume` 하나를 유지하고 직무별 참고표를 추가한다. 직무마다 스킬을 복제하면 사실 확인·양식 규칙이 중복된다. 직무명만 추가해도 각 직무에서 어떤 경력 증거를 확인해야 하는지 설명하기 어렵다. 따라서 공통 절차와 직무별 확인 자료를 연결하는 구성을 선택한다.

## 분류 단위와 15개 기능

한 사람이 독립적으로 책임지는 최종 산출물·성과를 분류한다. 복합 직무는 독립 책임으로 나누고 각 책임에 기능 코드 하나만 부여한다. 하나의 성과를 여러 기능의 별도 실적으로 중복 계산하지 않는다. 결과를 만드는 과정의 모든 행동을 별도 직무로 나누지는 않는다.

포함·제외 경계와 경계 사례는 [직무별 참고표](../../../skills/team-lead-resume/references/role-families.md)를 기준으로 한다. 대표 기능은 핵심 결과 책임, 명시된 평가 우선순위, 확인된 업무 비중 순으로 정한다. 근거가 부족하거나 우선순위가 같으면 대표 기능을 미확정으로 두고, 확인된 책임에 대한 경력 작성은 계속한다.

산업·서비스 분야, 기술·전문 수단, 역할·관리 범위, 운영 대상, 프로그램·업무 방식은 별도의 속성으로 기록한다. AI·데이터, AX·DX·SCM·ESG·PMO, 팀장 같은 명칭만으로 기능을 확정하지 않는다. 다른 기능을 맡는 팀장의 일상적인 코칭은 관리 범위로 기록한다. 프로젝트를 조율했다는 사실만으로 구현·승인·인사권이 있었다고 쓰지 않는다.

## 산출물과 수용 기준

- 공식 공고 12건(H1–H12)과 공식 지침 5건(G1–G5)을 출처 장부에 기록한다. 지침은 역할·문서 관련 3건과 분류 관련 2건(G4 ILO·ISCO, G5 NCS)이다. 직함만으로 직속 인원·인사권을 추정하지 않는다.
- `references/role-families.md`에 15개 기능의 책임·포함·제외 경계, 별도 속성, 확인할 증거, 지표의 정의·단위·집계 범위를 정리한다. 관련 공고와 자료를 확보하지 못한 영역도 연결해 기록한다. 공고의 요구와 편집 판단을 구분한다.
- 실제 공고의 독립 책임을 대조해 배정 누락·중복과 성과의 중복 계산을 확인한다. 불확실한 책임을 일반 운영·기타로 억지로 분류하지 않는다. 정보가 부족한 경우와 분류 경계에 공백이 있는 경우를 구분해 기록한다.
- 수주·인식 매출·미체결 파이프라인, 예상 절감·실현 절감, 지표의 분모·비교 집단, 코칭 행동·성과를 구분한다. 확인된 행동과 결과는 구체적으로 쓴다.
- SKILL의 검색 조건과 자료 선택 지침, 공통 증거표를 확장한다. 스킬 이름·기존 경력 계산기·지정 양식 우선 원칙은 유지한다.
- 개인 자료 없이 합성 과제를 적용하고 기존 판본과 새 판본의 원문·해시·관찰 범위를 기록한다. 기존 판본이 기준을 충족한 행동을 실패로 꾸미지 않는다.
- 개인 스킬 경로에서 작성·검증·저장한 뒤 공개 저장소에 반영한다. 기존 커밋과 동시 작업을 보존하며 일반 커밋으로 배포한다.

## 확보 범위와 검증 상태

기능분류의 범위와 확보한 공고의 범위는 다르다. F08의 생산·시공·의료·교육 등 본원 서비스와 F09의 고객지원·활용 정착을 전담하는 직무의 공고는 아직 확보하지 못했다. F13·F14·F15는 다른 공고에서 일부 책임을 확인한 수준이다. 비IT 연구·창작, 시설·설비·행정 등도 추가로 조사해야 한다. 자료를 확보하지 못한 분야는 사용자가 제공한 실제 공고와 경력으로 작성할 수 있으나, 조사하지 않은 자격·채용 요건을 지어내지 않는다.

C(영업·구매)·D(경영지원) 합성 과제는 MECE를 반영하기 전 후보를 대상으로 한 관찰 기록이다. 그 결과를 현재 15개 기능분류의 검증 결과로 옮기지 않는다. E 분류 검증에서는 25개 합성 사례가 수용 기준을 충족했다. 실제 출력과 해시는 별도 평가 기록에 보존한다. 한 번의 합성 과제 결과만으로 모든 직업을 포괄한다고 보장하지 않는다. 0.1.0의 테스트·설치·배포·원격 대조 기록은 당시 판본의 이력으로 보존한다. 이 설계 문서는 현재 수정본의 새 테스트 통과나 배포·원격 검증을 입증하지 않는다.

## 범위의 한계

15개 기능은 경력 근거의 선택과 책임 구분을 돕는 사용자 정의 분류다. ILO·NCS를 참고했다고 해서 모든 업종·직급·자격 요건을 대표하거나 공식 체계와 같아지는 것은 아니다. 공공·비영리·특수 전문직은 실제 업무·자격을 추가로 검토한다. 특정 자격·규제·산업 지식은 실제 공고와 지원자 자료로 확인한다. 실제 합격률·ATS 점수·직무 적격성은 예측하지 않는다. 기존 경력 계산기를 유지하고 새 계산기·외부 의존성은 추가하지 않는다.
