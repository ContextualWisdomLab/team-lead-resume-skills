# 팀장급 이력서 스킬 설계

## 목적과 범위

공식 채용 공고에서 팀장급의 책임을 확인하고, 지원자의 실제 경력과 연결해 이력서·경력기술서를 작성하는 재사용 스킬을 만든다. 첫 판은 한국어 IT·개발·데이터·AX 리더 직무를 중심으로 한다. 채용 공고의 요구를 실제 합격자에게서 확인한 사례로 해석하지 않는다.

사용자는 조사, 스킬 작성, 새 저장소 생성과 커밋을 요청했다. 아래 구현 방식은 작업자가 기본값으로 선택했으며, 사용자가 별도로 승인했다고 기록하지 않는다.

## 선택

- 기존 `korean-writing-skills`를 문장 편집·의미 보존 지침으로 연결한다. 새 저장소는 팀장급 직무 분석과 경력 증빙을 담당한다.
- 스킬 하나(`team-lead-resume`)와 필요한 근거 파일을 제공한다. 직무별 여러 스킬이나 별도 서버·UI는 만들지 않는다.
- 겹치는 재직 기간만 Python 표준 라이브러리로 계산한다. 유관 경력 인정·인사관리 적격성은 자동 판정하지 않는다.
- 개인 이력서와 연락처·보상정보를 저장소·평가에 포함하지 않는다. 예문과 평가는 합성 자료로 만든다.
- 새 저장소 이름은 `team-lead-resume-skills`로 정한다. 사용자의 후속 지시에 따라 GitHub 저장소를 공개한다. 원격 저장소를 만들기 전에는 로컬 커밋 상태와 스킬 설치 결과를 구분해 보고한다.

## 산출물과 책임

| 위치 | 책임 |
| --- | --- |
| `skills/team-lead-resume/SKILL.md` | 입력 확인, JD 대응, 근거 검토, 작성과 제출 점검 |
| `references/hiring-cases.md` | 실제 채용 공고와 이력서 지침, 출처·날짜·한계 |
| `references/evidence-workflow.md` | 권한·성과·경력·KPI 구분과 내부 근거표 |
| `references/writing-and-delivery.md` | 한국어 작성, 지정 양식, DOCX/PDF 검증과 전달 |
| `scripts/career_months.py` | 포함하기로 명시한 기간의 월 단위 합집합 계산 |
| `tests/`, `evaluations/` | 계산 검증과 합성 과제의 실제 관찰 기록 |

## 수용 기준

원문을 확인할 수 있는 고용주 공고와 지침을 출처별로 기록한다. 공고의 직무 설명(JD)에 적힌 요구와 작성자의 해석을 구별한다. 직속 인원과 프로젝트 인원, 기획과 구현, 산출물과 효과, 재직 기간과 경력 인정 여부를 구분한다. 자료에 없는 경력·수치·직함을 지어내지 않는다. 지정 양식을 우선하고 실제로 렌더링하지 않았다면 렌더링을 마쳤다고 주장하지 않는다. 설치 경로에서 형식 검사와 계산 테스트, 독립 합성 과제 확인을 마친 뒤 커밋한다.

## 한계

합격률, ATS 통과 점수, 직무 적격성을 예측하지 않는다. 소수의 공고가 시장 전체를 대표한다고 보지 않는다. 합성 과제의 통과를 실제 채용 효과나 일반적인 성능 향상으로 보고하지 않는다.
