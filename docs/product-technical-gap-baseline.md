## 개발 범위

PRD와 수용 기준은 [설계](superpowers/specs/2026-11-08-team-lead-resume.md)에, 기술 책임과 ADR은 [Architecture](../ARCHITECTURE.md)에 기록했다. 별도 서비스·DB·UML 클래스·ERD는 현재 제품에 해당하지 않는다. 새 기능은 실제 입력에서 드러난 오류나 요구를 근거로 추가한다.
